# 叠加混合亮斑

## Additive 是什么？

混合模式近似：**新颜色加到背景上**，只加光、不「涂抹遮挡」。  
火焰、激光、闪电光晕常用它。

本关材质已设为 Additive，并且：

```glsl
gl_FragColor = vec4(uColor * a, 1.0);
```

把能量乘进 RGB，alpha 固定为 1——和雨丝、闪电实现同一策略，避免 alpha 把亮度再削一层。

## 多层高斯

```glsl
float core = exp(-d * d * 40.0);   // 尖芯
float glow = exp(-d * d * 6.0) * 0.45; // 宽晕
```

`k` 越大峰越尖。这就是不用后处理 Bloom 时，手搓光晕的常用手法。

## 实验

1. 拉高强度，看亮斑如何「烧穿」背景网格。  
2. 在代码里把 `40.0` / `6.0` 对调，观察芯与晕角色互换。  
3. 阅读工程 `Lighting.ts` 闪照片元的天空抬亮，对照「只加光」。
