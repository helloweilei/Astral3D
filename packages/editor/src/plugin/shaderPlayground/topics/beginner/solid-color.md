# 纯色片元

## 这一节你要建立的直觉

片元着色器（fragment shader）会对**每一个像素**各执行一次 `main`。  
它不知道「物体叫什么名字」，只知道当前像素要算出一个颜色。

所以当你写：

```glsl
gl_FragColor = vec4(uColor * uIntensity, 1.0);
```

整屏都会变成同一种颜色——因为每个像素都得到同一个结果。

## 和「选中物体上色」有什么不同？

在建模软件里，你先选中一个杯子，再点红色。  
在片元着色器里，没有「选中」这回事：公式对覆盖到的每个像素统一生效。

## 实验

1. 拖动侧栏 **颜色**，看预览立刻变色。  
2. 把 **强度** 调到 `0.3`，整屏变暗。  
3. 在代码里把 `uColor * uIntensity` 改成 `vec3(1.0, 0.2, 0.2)`，忽略 uniform，强制红色。

## 关键词

- `gl_FragColor`：本像素最终颜色（Three.js / WebGL1 风格）  
- `uniform`：CPU（JS）每帧可改、所有像素共享的参数  
- `#ff0000`：可在代码注释或字符串里写十六进制颜色；编辑器会显示色块，点击可改色
