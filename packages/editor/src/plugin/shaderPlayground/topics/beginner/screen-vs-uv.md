# 屏幕坐标 vs UV

## 两种坐标

### 1. 屏幕坐标（左边）

```glsl
vec2 q = gl_FragCoord.xy / uResolution;
```

- 原点在画布左下（像素空间）  
- 跟 **窗口大小 / DPR** 有关  
- 天气里的「天空闪照」常用这种坐标做遮罩

### 2. Mesh UV（右边）

- 跟着几何走，和相机、分辨率无关（在本例全屏平面上两者看起来接近，但含义不同）  
- 适合「画在物体表面」的图案：丝带电弧、贴花、溶解

本页中间竖线：左半屏显示屏幕坐标染色，右半屏显示 `vUv` 染色。

## 实验

1. 拉宽或缩小浏览器窗口，观察**左边**是否跟着变。  
2. 把预览几何换成 **UV 平面**（透视下的方片），再对比左右差异。  
3. 在闪照片元思路里，天空用 `q.y` 做 `smoothstep`，只让上方变亮。

## 和闪电的对应关系

- **闪照 Pass**：屏幕坐标 + 天空遮罩  
- **电弧 Pass**：丝带 UV 横截面（离中线距离）
