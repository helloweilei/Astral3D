# 认识 UV

## UV 是什么？

可以把 UV 想成贴在几何表面的一张 **0～1 坐标纸**：

- 平面通常：左下接近 `(0, 0)`，右上接近 `(1, 1)`  
- 顶点着色器把网格自带的 `uv` 传给片元：`vUv = uv`

本知识点用：

```glsl
vec3 col = vec3(vUv.x, vUv.y, 0.4);
```

等于：横向越往右越红，纵向越往上越绿——你就「看见」了 UV。

## 为什么闪电要用 UV？

闪电丝带是一条细长四边形。横向 UV 从 `0→1`，**中心 `0.5` 就是电弧芯**。  
片元用「离中线多远」画白芯和蓝晕，靠的就是 UV，而不是识别图片。

## 实验

1. 改成 `vec3(vUv.x)`：只看横向。  
2. 改成 `vec3(fract(vUv.x * 8.0))`：看见竖条纹，理解「重复坐标」。  
3. 把预览几何切到 **球体**，观察 UV 如何包在曲面上。
