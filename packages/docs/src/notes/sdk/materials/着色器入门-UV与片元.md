# 着色器入门：UV 与片元

如果你觉得「闪电进阶」太陡，先从这篇和编辑器里的 **着色器沙盒** 插件开始。

## 用一句话建立直觉

- **顶点着色器**：决定每个顶点最终画在屏幕的哪儿。  
- **片元着色器**：对屏幕上（或三角形覆盖到的）**每一个像素**各算一次颜色。  

GPU **不会**知道「这是闪电还是空白」。它只跑你写的公式。公式算出来够亮就画；太暗你可以 `discard` 丢掉——看起来就像空白。

## UV 是什么？

`uv` / `vUv` 是几何自带的一张「坐标纸」，通常在 `0～1`：

- 平面：左下约 `(0,0)`，右上约 `(1,1)`  
- 闪电丝带：横向中心 `0.5` 表示电弧「芯」的位置  

片元里写 `gl_FragColor = vec4(vUv.x, vUv.y, 0.4, 1.0)`，等于把坐标纸染成颜色——你就「看见」UV 了。

## 屏幕坐标呢？

`gl_FragCoord.xy / resolution` 是**像素在画布上的位置**，和 mesh 的 UV 不是一回事。天气闪照常用屏幕坐标；电弧横截面常用丝带 UV。

## 建议学习顺序

1. 打开编辑器 → **插件中心** → **着色器沙盒**  
2. 难度选 **入门**：纯色 → 认识 UV → 屏幕 vs UV  
3. **进阶**：距离成圆（体会 discard）→ 时间闪烁  
4. **精通**：叠加混合 → 闪电丝带剖面  
5. 再读 [着色器进阶：以闪电效果为例](./着色器进阶-闪电案例.md)

## 如何自己加知识点？

沙盒用注册表扩展，难度永远只有三档。新增一个 Topic 文件并 `registerTopics` 即可，不必改 UI。详见插件目录：

`packages/editor/src/plugin/shaderPlayground/topics/`
