# 场景命令

场景命令负责整体场景替换。

## SetSceneCommand

| API | 参数 | 说明 |
| --- | --- | --- |
| `constructor(scene)` | `scene: THREE.Scene` | 用新场景替换当前场景。 |
| `cmdArray` | `Command[]` | 拆分后的命令数组。 |

执行时会把场景内对象拆成命令执行，撤销时恢复旧状态。

## 使用建议

整体替换场景影响范围很大。导入新工程前，先确认旧场景是否需要保存；替换后要重点验证相机、脚本、材质引用、图纸状态和历史栈。
