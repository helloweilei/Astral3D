# 着色器沙盒

内置插件，用于在编辑器里**实时编写并预览** GLSL。

## 入口

插件中心 → **着色器沙盒**。

## 能力

- **三档难度**：入门 / 进阶 / 精通（固定）  
- **知识点可扩展**：每档下列表不限长度；每个知识点对应一份完整 Markdown 文档  
- **新标签预览文档**：沙盒内点「新标签预览文档」在浏览器新 Tab 打开渲染后的文档  
- 左栏选知识点，右栏独立 WebGL 预览；改代码约 300ms 防抖应用；GLSL 编辑器支持 `#RRGGBB` 色块取色  
- 自由模式：不绑定知识点，随意实验  

## 扩展知识点

1. 在 `packages/editor/src/plugin/shaderPlayground/topics/<grade>/` 新增 `xxx.md`（完整文档）与 Topic 定义  
2. `import doc from './xxx.md?raw'` 赋给 `docMarkdown`  
3. 在 `topics/index.ts` 的 `registerTopics([...])` 中追加  

工作台 UI 无需修改。
