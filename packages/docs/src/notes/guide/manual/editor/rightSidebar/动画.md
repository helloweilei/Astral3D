# 右侧「动画」面板

本面板用于：**查看当前选中物体的动画列表**、改 **播放速率**、管理导入资源自带的动画。

**从零打关键帧、时间轴编辑**不在这里，请看：[动画编辑器](/guide/5s7acuj0/)（底部面板）。

## 你会在这里做什么

1. 选中带动画的物体后，列表里会出现动画条目。
2. 可调整全局 **播放速率**（影响 mixer）。
3. 对已有动画做播放相关操作（与底部工具栏配合）。

## 从零做一段位移动画（摘要）

完整逐步说明见上方链接，最短路径：

1. 选中物体 → 打开底部 **动画编辑器** → **+** 新建动画  
2. 时间在 0 → 右侧 **物体 → 位置** 旁菱形打第 1 帧  
3. 拖时间轴 → 改位置 → 再打第 2 帧 → 播放  

右侧「动画」只负责列表与速率，**打关键帧靠物体面板上的菱形 + 底部时间轴**。
