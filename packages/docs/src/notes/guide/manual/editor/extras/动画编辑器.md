# 动画编辑器：从零做一段动画

这篇只讲**怎么点、按什么顺序做**。做完你会得到：一个立方体从 A 点移到 B 点的动画。

---

## 0. 先认界面

| 位置 | 做什么 |
| --- | --- |
| 场景视口 | 选中物体、用 Gizmo 改位移/旋转/缩放 |
| 右侧「物体」面板 | 看数值；标签旁有 **菱形小点** =「在当前时间加关键帧」 |
| 底部「动画编辑器」 | 动画列表、时间轴、关键帧圆点 |
| 右侧「动画」面板 | 播放速率、导入的 glTF 动画列表（可选） |

没有底部面板时：点编辑器底部栏里的 **动画编辑器** 打开。

---

## 1. 准备一个物体（30 秒）

1. 场景里放一个物体（例如立方体），或选中已有物体。
2. **必须保持选中**。未选中物体时，动画编辑器里加动画会直接报错「请先选中模型」。

---

## 2. 新建一条空动画

1. 打开底部 **动画编辑器**。
2. 左上角下拉目前可能是空的；点旁边的 **+（新建动画）**。
3. 系统会创建一条默认名类似 `动画` 的空剪辑，并自动选中它。
4. 左侧会出现以该物体为根的轨道树；右侧时间轴先几乎是空的（没有关键帧圆点）。

到这里：**动画壳子有了，内容还没有**。

---

## 3. 在第 0 帧记下「起始姿势」（第一帧）

1. 确认时间轴播放头在 **最左边（0 时刻）**。  
   - 可用顶部工具栏 **跳到首帧**。
2. 确认物体在你想要的**起始位置**（必要时用 Gizmo 摆好）。
3. 打开右侧 **物体** 面板。
4. 找到 **位置** 一行，点标签左边的 **菱形**（提示：添加关键帧）。
5. 回到底部时间轴：应出现 **position** 相关轨道，并在 0 处有一个关键帧点。

同样方式可对 **旋转**、**缩放** 各打一帧（旋转轨道存的是四元数，界面仍显示欧拉角编辑）。

> 播放中不能加关键帧。若点了没反应，先 **停止** 再加。

---

## 4. 拖时间 → 改姿势 → 再打一帧（第二帧）

1. 在时间轴上 **点击或拖动** 播放头，挪到后面（例如大约 1～2 秒处；刻度单位是毫秒）。
2. **不要先点播放**。用视口 Gizmo 把物体拖到 **结束位置**。
3. 再点右侧 **位置** 旁的菱形，打第二帧。
4. 时间轴上同一轨道应出现两个关键帧点。

时长会自动拉长到「最后一个关键帧所在时间」。

---

## 5. 预览

1. 点动画编辑器顶部的 **播放**。
2. 物体应在两帧之间插值移动。
3. **暂停 / 继续 / 停止**、**跳到首帧 / 末帧** 在同一组按钮里。
4. 右侧 **动画** 面板可改 **播放速率**（全局 mixer 速率）。

---

## 6. 改关键帧 / 删关键帧

| 操作 | 做法 |
| --- | --- |
| 改某一帧的姿势 | 把播放头拖到该关键帧附近 → 改物体变换 → **再点一次菱形**（同属性会覆盖该时刻的值） |
| 移动关键帧时间 | 在时间轴上拖关键帧圆点 |
| 删除关键帧 | 在时间轴选中关键帧 → **右键** →「删除选中的关键帧」 |
| 切换动画 | 左上角下拉切换当前剪辑 |

---

## 7. 子物体动画（可选）

若改的是 **父模型下的子网格**：

1. 选中子物体，对其位移等打关键帧。
2. 点动画编辑器左上角 **锁** 图标（锁定父模型）。  
   锁定后，选中切换时，仍编辑「锁住的那一套」动画，避免一选父节点轨道就乱跳。

---

## 8. 最短检查清单（复制着用）

```text
□ 选中场景物体
□ 打开底部「动画编辑器」→ 点 + 新建动画
□ 播放头在 0 → 摆好起始姿势 → 右侧「位置」旁菱形打帧
□ 播放头拖到后面 → 摆好结束姿势 → 再打一帧
□ 点播放预览
□ 需要时：停止后再改帧 / 右键删帧
```

---

## 预置：昼夜交替

动画面板顶栏 **预置昼夜交替**：

1. 填写 **太阳距离**（默认 200）与 **太阳尺寸** 后确定  
2. 仅加入「昼夜交替」组：远处太阳球体 + 平行光 + 环境光  
3. 选中该组或其子节点 → **播放**（约 48 秒一循环）：球体绕转，场景明暗变化（含环境贴图强度）  
4. 阴影：只对你开启了投射/接收的物体生效  

选中该组后，顶栏可继续调节距离与尺寸。

---

## 常见卡点

| 现象 | 原因 / 处理 |
| --- | --- |
| 点 + 报错 | 没选中物体 |
| 点菱形没反应 | 正在播放 → 先停止；或未选中带动画的物体 |
| **打了两帧却没有过渡、像瞬移** | 见下方「为什么没有过渡动画」 |
| 只有导入模型能播、自己打的播不了 | 确认当前下拉选中的是你新建的那条动画，且至少有两帧 |
| 改了旋转界面数值，轨道名却是 quaternion | 正常：旋转以四元数写进轨道 |
| 想撤销打帧 | 当前**没有**撤销栈，只能删关键帧重打 |

---

## 为什么没有过渡动画？

插值是有的（线性），出现「直接跳过去」通常是下面几种操作问题，不是系统不做过渡。

### 1. 两帧打在了同一时刻（最常见）

菱形写入的是**当前播放头时间**的姿势。若：

1. 在 0 打了位置 A  
2. **没有拖动时间轴**  
3. 把物体挪到 B，再点一次菱形  

→ 只会**覆盖** 0 时刻那一帧，轨道上始终只有一个点，播放时当然不会动。

正确：第一帧后先把绿色播放头拖到后面（时间轴上应看到两个分离的圆点），再改位置、再打第二帧。

### 2. 打完最后一帧后直接点播放

打第二帧时播放头一般停在**结尾**。`播放` 是从**当前时间**继续，不会自动回到 0。

- 已在结尾 → 看起来像「没动画」或循环时 **瞬间闪回起点**（像跳变）  
- 处理：先点 **跳到首帧**（或 **停止**），再点 **播放**

### 3. 时间轴刻度显示成「秒」

顶栏刻度按秒取整显示（`00:00`）。在同一秒内挪播放头，看起来没动，其实时间变了，两帧间距可能只有零点几秒，肉眼像瞬移。把两帧拉开到大约 1～2 秒再预览。

### 4. 自检

时间轴同一 `position` 轨道上是否有 **至少两个、左右分开的圆点**？有的话：跳到首帧 → 播放，应能看到过渡。

---

## 和右侧「动画」面板的关系

- **动画编辑器（底部）**：创建 / 编辑关键帧、时间轴。
- **动画（右侧）**：看列表、改速率、管理从 glTF 带来的动画；**不能替代**「菱形打关键帧」这一步。

从零做关键帧动画：**底部编辑器 + 右侧物体面板菱形**，缺一不可。
